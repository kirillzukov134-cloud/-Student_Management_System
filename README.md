# Система управления успеваемостью студентов (Student Management System)
## Обоснование выбора темы
Я выбрал эту тему, потому что хотел разобраться, как работают сайты с базами данных. В университете или школе всегда нужно где-то хранить список студентов и их оценки. Обычно это делают в Excel, но это неудобно — файлы теряются, формулы ломаются. И поэтому, для меня это была хорошая практика - научиться писать SQL-запросы, работать с формами, таблицами и делать их простыми, но при этом красивым и интересным интерфейсом

##  Основной функционал

###  Студенты
- Добавление нового студента (имя, фамилия, группа, дата рождения, e-mail, телефон)
- Редактирование данных студента
- Удаление студента
- Просмотр всех студентов

###  Предметы
- Добавление нового предмета
- Редактирование названия предмета
- Удаление предмета

###  Оценки
- Выставление оценки (2, 3, 4, 5) студенту по предмету
- Редактирование оценки
- Удаление оценки
- Просмотр всех оценок студента с автоматическим подсчётом среднего балла

## База данных (БД)
У нас есть три гланые таблицы:
- Студенты - личные данные: имя, фамилия, в какой группе учится, дата рождения, email, номер телефона
- Предметы - список названий предметов
- Оценки - связующая таблица (кому и за что оценка поставлена)
- Преподаватели - те, кто ведёт предметы. Храним имя, фамилия и телефон
- Группы - список групп. У каждой группы есть название и специальность
- Расписание - показывает, в какой день недели у какой группы какой предмет
